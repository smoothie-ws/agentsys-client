# AgentSys Client 0.1.0

Initial MVP of the independent static browser application.

- Graph editor, Library, collections, execution controls and multiple server environments over Web API 1.0.
- Sandboxed Plugin API 1, package format 1 and TypeScript SDK 0.1.0.
- Plugin lifecycle and content replacement by checksum, ID dependencies and explicit permission review.
- Browser storage namespace `agentsys.client.v1`.
- Static ZIP and optional Node.js 22+ CLI, with runtime server configuration.

See INSTALLATION.md and docs/plugins.md.
